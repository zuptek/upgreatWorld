# 🟡 There is also a technical/SEO issue I want you to fix

I found evidence that **search-engine indexed versions are lagging behind the current live build**.

For example, the current directly opened homepage shows:

**500+ / 20+ / 7 / 98%**. ([UpGreat World][1])

But a recent search-engine result still contains the previous:

**333+ / 13+ / 4 / 65%**. ([UpGreat World][12])

Likewise, older indexed versions contain different contact information and older copy. ([UpGreat World][12])

This means you're likely dealing with a **crawl/cache/index consistency problem**, not necessarily that the current page itself is wrong.

### Check:

* canonical URLs
* sitemap
* robots.txt
* redirects
* duplicate `.html` vs clean URLs
* Google Search Console indexing
* stale cached versions
* internal links
* structured data
* page `lastmod`
* old URLs still being indexed

Your `.html` URLs do redirect to the cleaner URLs, which is good. For example, `case-studies.html` redirects to `/case-studies`, and `contact.html` redirects to `/contact`. ([UpGreat World][3])
